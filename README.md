# ЯЖЕМОХ — интерактивная мастерская

Сайт Ивана Чубатова: предметный дизайн и инженерия. Трёхмерная комната с рабочим столом, ретрокомпьютером, кулоном, светильником и папкой проектов.

## Разработка на GitHub

Репозиторий: https://github.com/VaniaZet/yazhemoh-workshop. Здесь хранится рабочий код сайта и оптимизированные модели; тяжёлые CAD-исходники остаются отдельно.

```sh
git clone https://github.com/VaniaZet/yazhemoh-workshop.git
cd yazhemoh-workshop
python scripts/serve.py
```

Открыть http://127.0.0.1:8000/. Для проверок нужен Node.js 24, для локального сервера — Python 3. Установка npm-пакетов и сборка не требуются.

Изменения делать в отдельной ветке и отправлять через pull request в `main`. Для небольшой личной правки допустим обычный коммит в `main`. Перед отправкой:

```sh
node scripts/check-models.mjs
node scripts/check-product-loader.mjs
node scripts/check-printer.mjs
```

Те же проверки запускаются в GitHub Actions после обновления `main` и в pull request. Приватность репозитория сохраняется. Автоматическая публикация сайта из GitHub пока не подключена.

Текущая размещённая версия: https://yazhemoh-workshop.chubatovz.chatgpt.site/. Она обновляется отдельно; коммит в GitHub сам по себе её не меняет.

## Запуск

Статический сайт без сборки и внешних CDN. Содержимое `dist/` готово для обычного статического хостинга. Локально: `python scripts/serve.py --port 4173` или `run-local.bat`. Сервер задаёт корректный MIME-тип JavaScript независимо от настроек Windows.

## Устройство

- `dist/app.js`: процедурная сцена Three.js, модели, содержимое карточек, проекция интерактивных меток и raycasting.
- `dist/software-renderer.js`: запасной рендерер на Canvas 2D с буфером глубины, если WebGL недоступен.
- `dist/style.css`: интерфейс и мобильная композиция.
- `dist/vendor/`: локальные Three.js и шрифт Inter с лицензиями.
- `.openai/hosting.json`: идентификатор сайта и каталог публикации.

Прямые ссылки: `#pendant`, `#firefly`, `#portfolio`, `#engineering`, `#about`.

В режиме WebGL используются тени и отдельная среда отражений в просмотрщике. При отсутствии WebGL сцена и вращение остаются доступны в упрощённом освещении. Камера комнаты фиксирована; модель в карточке вращается перетаскиванием, масштабируется колесом, возвращается кнопкой «Ракурс». Esc закрывает карточку. Есть дневной и вечерний свет и быстрый доступ через меню.

## Продолжение

Подвеска и светильник импортированы из авторских STL/FBX. Стол импортирован из финального `table-web.glb`, подготовленного из `стол.obj`: эллиптические фанерные детали, красный паракорд и центральная металлическая стойка. Программной реконструкции нитей больше нет. Для комнаты используется 21 499 треугольников, для осмотра — исходные 116 820 треугольников финального GLB.

`dist/product-models.js` загружает индексированные сетки из `dist/models/`, с отдельной облегчённой версией для комнаты и детальной для осмотра. Детали загружаются при открытии карточки. Сжатие gzip распаковывается через DecompressionStream; внешних CDN нет. Исходные данные и контрольные суммы записаны в `dist/models/provenance.json`. Повторный импорт: `blender -b --python scripts/prepare-models.py -- <каталог-исходников> <каталог-dist/models>`. Названия входных файлов см. в скрипте. Исходные файлы остаются без изменений.

Материалы настроены для сайта: шлифованный/тёмный титан, голубая светящаяся оплётка, серый корпус; у стола — тёмная фанера, красный паракорд и светлый металл. Это визуальная настройка по известным материалам, не измеренные PBR-текстуры.
Покупки и корзины нет. Кнопки ведут в подтверждённый профиль Instagram @yazhemoh; цены не заданы. Далее добавить реальные фотографии, данные портфолио и подтверждённые ссылки покупки.

См. QA.md. Результаты проверок разделены по версиям; ограничения предыдущих проверок относятся к указанным в них сессиям.

## Bambu Lab A1

`dist/printer.js` содержит эскизную модель принтера на виброопорах. `dist/printer-motion.js` задаёт ограниченные траектории и малое покачивание. Нажатие на принтер или подпись над ним ставит анимацию на паузу. При открытой карточке предмета печать временно останавливается. Проверка диапазонов: `node scripts/check-printer.mjs`.

## Проверка импортированных моделей

`node scripts/check-models.mjs` проверяет все шесть сеток: размеры буферов, индексы, конечность координат, единичные нормали, вертикальную ось и сохранение пропорций. Геометрия для комнаты и осмотра использует общие кэшированные ресурсы; закрытие карточки их не уничтожает.

Для отдельного обновления стола: `blender -b --python scripts/prepare-table.py -- <путь-к-table-web.glb> dist/models`. Draco декодируется при подготовке в Blender. В браузере используется существующий локальный загрузчик gzip-сеток; дополнительные декодеры не нужны.
