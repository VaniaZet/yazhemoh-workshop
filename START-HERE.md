# Исходный код YAZHEMOH

Рабочая версия сайта, обновлённая 18 ноября 2026 года.
Основной репозиторий разработки: https://github.com/VaniaZet/yazhemoh-workshop.
Основана на опубликованной версии Sites 3 (коммит 3e0bdc73745bed4cbb24f343e8df077fccc86c27).
Новые изменения пока не опубликованы: соединение с сервером исходников Sites недоступно.

## Запуск в Windows

1. Распакуйте весь ZIP в отдельную папку.
2. Если Python 3 установлен, запустите run-local.bat.
3. Откройте http://localhost:8000 в браузере.
4. Для остановки закройте окно сервера или нажмите Ctrl+C.

Если Python отсутствует, установите Python 3. Вручную, из папки проекта:

```
python scripts/serve.py
```

На macOS/Linux используйте python3 вместо python.
Не открывайте index.html двойным щелчком: ES-модулям и загрузке моделей нужен HTTP-сервер.

## Состав

- dist/ — готовый сайт: HTML, CSS, JavaScript, модели, локальная Three.js, шрифты и лицензии зависимостей.
- scripts/ — сервер локального запуска, подготовка моделей и проверки.
- README.md — устройство приложения и дальнейшая разработка.
- QA.md — выполненные проверки и известные ограничения.
- .openai/hosting.json — настройки исходного размещения. Для обычного статического хостинга этот файл не требуется.

Архив не включает историю Git и исходные тяжёлые CAD-файлы. Все адаптированные модели, необходимые работающему сайту, включены. Установка npm-зависимостей и сборка для запуска не нужны.

В этой рабочей версии подключён новый стол из `table-web.glb`: настоящая сетка паракорда, эллиптические детали и стойка. Для запуска GLB и Blender не нужны: готовые сетки уже включены в `dist/models/`. Порядок продолжения работы см. в `PROJECT-CONTEXT.md`.
