# Продолжение разработки YAZHEMOH

18 ноября 2026 года. Основной репозиторий для дальнейшей разработки: https://github.com/VaniaZet/yazhemoh-workshop. Репозиторий публичный по разрешению пользователя от 19 ноября 2026 года. Исходно в main был только README (коммит bdc812d0c70a2e015b71e1daf8b369a11d5e6472). Рабочие исходники находятся в корне репозитория, готовый сайт — в dist/.

Перенос выполнен через веб-интерфейс GitHub с сохранением исходного коммита README. При переносе GitHub-подключение возвращало 404 для приватного репозитория, а исходящие Git-соединения были недоступны. После изменения публичности подключение GitHub читает репозиторий. Запись через API в этой сессии отклонена (403); правки выполняются через веб-интерфейс. При следующей работе сначала проверить доступ и актуальный main. Местный .git инициализирован и origin указан, но история с GitHub не загружена: для обычной Git-разработки безопаснее свежий git clone в новую папку после восстановления доступа.

## Сделано в рабочем проекте

- Подвеска и светильник уже были импортированы в версии 3 из авторских STL/FBX. Их существующие сетки и материалы сохранены.
- Старый стол с реконструированными нитями заменён финальным `E:\Сайт\Модели\table-web.glb`. Исходник финального GLB — `стол.obj`. Настоящая геометрия паракорда, центральной стойки и двух эллиптических плоских деталей присутствует.
- Сайт использует прежний локальный загрузчик индексированных gzip-сеток. GLB декодирован Blender при подготовке; браузеру Draco не требуется. Подключённые файлы: `dist/models/table-room.*` и `table-detail.*`.
- Комната: 21 499 треугольников; осмотр: исходные 116 820 треугольников финального GLB. Цвета стола: тёмные детали, красный паракорд, светлая металлическая стойка.
- Удалено программное создание нитей и стойки в `dist/product-models.js`. Масштаб и положение моделей вычисляются по реальному Box3, включая точное касание пола и центр карточки.
- Исправлен локальный сервер Windows: запуск через `run-local.bat` или `python scripts/serve.py --port 4173`. Обычный `python -m http.server` на этом компьютере выдавал JS как text/plain.
- Обновлены проверки, provenance, README, START-HERE и QA. Полные результаты см. в QA.md.

## Проверки

`node scripts/check-models.mjs`, `node scripts/check-product-loader.mjs`, `node scripts/check-printer.mjs` проходят. ## Публикация и продолжение

- Основной сайт: https://vaniazet.github.io/yazhemoh-workshop/.
- GitHub Pages настроен на Source: GitHub Actions. Workflow `.github/workflows/pages.yml` запускается при push в main или вручную; перед публикацией проверяет JS, модели, загрузчик и движение принтера. Публикуется только каталог dist/.
- Репозиторий стал публичным по явному разрешению пользователя. Тяжёлые CAD-исходники в репозиторий не включены; браузерные сетки публичны.
- Разработку продолжать в этом репозитории с проверкой актуального main. Публикация ChatGPT Sites (последняя подтверждённая версия 3) хранится отдельно и не обновляется коммитами GitHub.
- Местная .git-история не загружена с GitHub; для обычной Git-разработки после восстановления сетевого доступа использовать свежий clone в новую папку.

Для пересоздания только сеток стола: `blender -b --python scripts/prepare-table.py -- <table-web.glb> dist/models`.
Общий `prepare-models.py` теперь принимает реальные имена файлов из папки `Модели` и использует тот же финальный GLB стола.

Отдельные новые GLB светильника/подвески, подготовленные ранее в `%TEMP%\yazhemoh-continue\web-models`, НЕ подключены: существующие оптимизированные авторские сетки сайта уже подходят и легче для комнаты. Не путать их с подключёнными сетками.
